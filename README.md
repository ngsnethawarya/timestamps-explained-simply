# Timestamps Explained Simply

Unix timestamps confused me until I stopped overthinking them.

This small project converts Unix timestamps into human-readable dates. I built it while learning how timestamps appear in logs, forensic investigations, and security events.

## Why this matters

Almost every cybersecurity tool records events using timestamps.

Understanding them helps when:

- Reading log files
- Investigating incidents
- Building timelines
- Reviewing SIEM alerts

## Example

Input

1704067200

Output

2024-01-01 00:00:00 UTC

## What I learned

- What a Unix timestamp is
- Why systems use epoch time
- How to convert timestamps using Python
- Why timestamps are important during investigations

This repository is part of my cybersecurity learning journey.
